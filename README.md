## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/RR024/RR-portfolio.git
```

Move into the project folder:

```bash
cd RR-portfolio
```

---

## ▶ Run Locally

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Using VS Code

Install the **Live Server** extension, then:

* Right click `index.html`
* Click **Open with Live Server**

### Option 3: Using Python

```bash
python3 -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```

## 🌐 Deployment

### GitHub Pages

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/RR024/RR-portfolio.git
git push -u origin main
```

Then enable GitHub Pages from:

**Settings → Pages → Deploy from main branch**

### Netlify

* Drag and drop the project folder, or
* Connect the GitHub repository and deploy

### Vercel

* Import the GitHub repository
* Deploy the project
